# 计费与 Dashboard 领域词汇

- **计费单元（billing unit）**：一个 Plan 合约、凭证级订阅或智能体订阅实例。每个计费单元有自己的 `period_start`，周期起点按该时间锚定，不按自然月一号推断。
- **周期账单（period charge）**：代理账本中某计费单元某一周期的原币金额。`recurring_charge`、币种和周期边界在创建后不可变。
- **冻结（finalized）**：财务金额已经确认；`finalized_at` 非空。人民币账单立即冻结，外币账单使用周期起点汇率或最近可用汇率后冻结；完全没有汇率时保持待处理。
- **分摊快照（allocation）**：智能体周期账单在 `period_start` 取得的有效软件绑定及分摊金额。周期内绑定变化只影响下一周期。
- **Dashboard 投影**：从已冻结周期账单和请求增量生成的归档数据。冻结的订阅费用只在首次写入时确定，后续导出不得覆盖。
- **账户排除（account exclusion）**：Dashboard 归档中的稳定 `account_id` tombstone。排除会阻止账户镜像、用量、订阅费和等价成本再次写入；同名但新 ID 的账户不受影响。
- **零额周期**：代理账本保留用于审计的零金额周期；没有等价成本时不写入 Dashboard，也不使账户出现在用户列表。
- **高水位（export high-water mark）**：已成功提交到 Dashboard 的请求日志最大 ID。上传或本地提交失败时不得推进。

调价从下一计费周期生效；本周期取消只影响服务停止，不修改已冻结账单，也不退款。未来退款应使用独立冲正条目，而不是改写原账单。
